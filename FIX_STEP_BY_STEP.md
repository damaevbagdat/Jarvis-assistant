## 🔴 ШАГ 1: Исправить PostgreSQL память разговоров

### 1.1. Откройте Supabase Dashboard

**Действие:** Откройте в браузере: https://supabase.com/dashboard

**Что делать:**
1. Войдите в свой аккаунт Supabase
2. Выберите ваш проект (который используется для Jarvis)
3. Если проекта нет → создайте новый (бесплатно):
   - New Project
   - Name: `jarvis-bot`
   - Database Password: придумайте и **сохраните** (понадобится позже)
   - Region: ближайший к вам
   - Plan: Free

**✅ Результат:** Вы в Supabase Dashboard вашего проекта

---

### 1.2. Создайте таблицу для памяти

**Действие:** В Supabase перейдите: **SQL Editor** (левое меню)

**Что делать:**
1. Нажмите "+ New query"
2. Скопируйте содержимое файла `setup_postgres_memory.sql`:

```sql
-- Скопируйте ВСЁ содержимое из файла setup_postgres_memory.sql
-- Или используйте этот короткий вариант:

CREATE TABLE IF NOT EXISTS n8n_chat_histories (
    id SERIAL PRIMARY KEY,
    session_id VARCHAR(255) NOT NULL,
    type VARCHAR(50) NOT NULL,
    content TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_session_id ON n8n_chat_histories(session_id);
```

3. Нажмите **RUN** (или F5)
4. Внизу должно появиться: "Success. No rows returned"

**✅ Результат:** Таблица `n8n_chat_histories` создана

**Проверка:** Перейдите в **Table Editor** (левое меню) → должна быть таблица `n8n_chat_histories`

---

### 1.3. Получите connection параметры PostgreSQL

**Действие:** В Supabase перейдите: **Settings** → **Database**

**Что скопировать:**
1. **Host:** `db.xxxxxxxxxxxxx.supabase.co` (скопируйте)
2. **Database name:** `postgres`
3. **Port:** `5432`
4. **User:** `postgres`
5. **Password:** (тот, что вы задали при создании проекта)

**💡 Совет:** Откройте Notepad и запишите эти параметры - они понадобятся в следующем шаге.

**✅ Результат:** У вас есть все параметры подключения

---

### 1.4. Настройте PostgreSQL credential в n8n

**Действие:** Откройте в новой вкладке: https://n8n.kir-ito.ru/

**Что делать:**

1. **Перейдите в Credentials:**
   - Settings (шестеренка внизу слева)
   - Credentials

2. **Найдите PostgreSQL credential:**
   - Поиск: введите `P8hk2UZbE9YDsHIB`
   - Или найдите "Postgres account" в списке
   - Кликните на него

3. **Введите параметры из Supabase:**
   ```
   Host: db.xxxxxxxxxxxxx.supabase.co  (из Supabase)
   Database: postgres
   User: postgres
   Password: [ваш пароль из Supabase]
   Port: 5432
   ```

4. **Важно! Включите SSL:**
   - Прокрутите вниз
   - Найдите параметр **SSL**
   - Выберите: **require** (или **prefer**)

5. **Проверьте подключение:**
   - Нажмите кнопку **Test connection** внизу
   - Должно появиться: ✅ "Connection test successful"

6. **Сохраните:**
   - Нажмите **Save**

**⚠️ Если тест не прошёл:**
- Проверьте пароль
- Убедитесь что SSL включен
- Проверьте Host (должен быть без "https://" и без пробелов)

**✅ Результат:** PostgreSQL credential настроен и проверен

---

### 1.5. Проверьте узел в workflow

**Действие:** В n8n откройте ваш workflow

**Что делать:**

1. **Откройте workflow:**
   - Workflows (левое меню)
   - Найдите "+ paraplexity 3,0"
   - Кликните на него

2. **Найдите узел Postgres Chat Memory:**
   - Используйте поиск (Ctrl+F) → введите "Postgres"
   - Или визуально найдите узел с названием "Postgres Chat Memory"

3. **Проверьте настройки узла:**
   - Кликните на узел
   - Убедитесь что выбран credential "Postgres account"
   - Параметры должны быть:
     ```
     Session ID Type: Custom Key
     Session Key: ={{ $('Telegram Trigger').item.json.message.chat.id }}
     Context Window Length: 3 (или больше)
     ```

4. **Сохраните workflow:**
   - Нажмите **Save** вверху справа

**✅ Результат:** Workflow настроен на использование PostgreSQL памяти

## 🔴 ШАГ 2: Исправить OpenRouter для изображений

### 2.1. Проверьте OpenRouter аккаунт

**Действие:** Откройте: https://openrouter.ai/

**Что делать:**

1. **Войдите в аккаунт:**
   - Sign In (или зарегистрируйтесь если нет аккаунта)

2. **Проверьте кредиты:**
   - Перейдите в **Credits** (верхнее меню)
   - Посмотрите баланс

**Если баланс $0.00:**
- Нажмите **Add credits**
- Минимум: $5 (хватит на ~500-1000 изображений)
- Добавьте карту и пополните баланс

**✅ Результат:** На балансе есть кредиты

---

### 2.2. Получите (или проверьте) API Key

**Действие:** На OpenRouter перейдите: **Keys** → **API Keys**

**Что делать:**

1. **Если есть ключ:**
   - Скопируйте его (нажмите на иконку копирования)
   - Или создайте новый: **Create Key**

2. **Если нет ключей:**
   - Нажмите **Create Key**
   - Name: `jarvis-bot`
   - Нажмите **Create**
   - **ВАЖНО:** Скопируйте ключ СЕЙЧАС (он больше не покажется!)

**💡 Совет:** Сохраните ключ в `.credentials/TOKENS.md`

**✅ Результат:** У вас есть OpenRouter API Key

---

### 2.3. Обновите OpenRouter credential в n8n

**Действие:** Вернитесь в n8n: https://n8n.kir-ito.ru/

**Что делать:**

1. **Перейдите в Credentials:**
   - Settings → Credentials

2. **Найдите OpenRouter credential:**
   - Поиск: введите `z0vBSqt6SlKhroIR`
   - Или найдите "OpenRouter" в списке
   - Кликните на него

3. **Обновите API Key:**
   - Вставьте новый API Key из OpenRouter
   - Формат: `sk-or-v1-xxxxxxxxxxxxxxxxxxxx`

4. **Сохраните:**
   - Нажмите **Save**

**⚠️ Важно:** Credential для OpenRouter называется "OpenRouter" или может называться по-другому, но ID должен быть `z0vBSqt6SlKhroIR`

**✅ Результат:** OpenRouter API Key обновлен

---

### 2.4. Проверьте узлы для изображений в workflow

**Действие:** В workflow проверьте узлы анализа изображений

**Что делать:**

1. **Найдите узел "Photo to text":**
   - Поиск (Ctrl+F) → "Photo to text"
   - Кликните на узел

2. **Проверьте настройки:**
   ```
   Resource: image
   Operation: analyze
   Model: gpt-4o-mini
   Credentials: OpenRouter (z0vBSqt6SlKhroIR)
   ```

3. **Найдите узел "Photo to text1":**
   - Это второй узел для изображений
   - Проверьте те же настройки

4. **Сохраните workflow:**
   - Save

**✅ Результат:** Узлы настроены на OpenRouter

## 🔴 ШАГ 3: Протестировать исправления

### 3.1. Тест памяти разговоров

**Действие:** Откройте Telegram → @Baga_assistant_bot

**Что отправить:**

1. **Представьтесь:**
   ```
   Меня зовут Багдат
   ```

2. **Подождите ответ** (5-10 секунд)

3. **Проверьте память:**
   ```
   Как меня зовут?
   ```

**✅ Ожидаемый результат:** Бот ответит с упоминанием вашего имени "Багдат"

**❌ Если не работает:**
- Откройте n8n → Executions
- Найдите последнее выполнение
- Проверьте узел "Postgres Chat Memory" на ошибки
- Проверьте в Supabase → Table Editor → `n8n_chat_histories` → должны появиться записи

---

### 3.2. Тест анализа изображений

**Действие:** В том же чате с ботом

**Что отправить:**

1. **Отправьте любое изображение**
   - Например, скриншот экрана
   - Или любое фото

2. **Подождите 10-15 секунд**
   - Анализ изображений медленнее текста

**✅ Ожидаемый результат:** Бот ответит с описанием содержимого изображения

**❌ Если не работает:**
- n8n → Executions → последнее выполнение
- Проверьте узлы:
  - "Download Photo"
  - "Fix mimeType1"
  - "Photo to text"
- Смотрите текст ошибки
