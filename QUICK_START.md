# Быстрый старт Jarvis Assistant

## 🚀 Минимальные действия для запуска бота

### Шаг 1: Проверьте n8n (2 минуты)

1. Откройте https://n8n.kir-ito.ru/
2. Найдите workflow "paraplexity 3.0"
3. Убедитесь, что он **активен** (переключатель справа должен быть включен)
4. Если неактивен - активируйте его

### Шаг 2: Критические credentials (5 минут)

Минимум для работы бота - это 3 сервиса:

#### 1️⃣ Telegram Bot API ✅
Уже настроен! Ничего делать не нужно.

#### 2️⃣ Google Gemini API ⚠️
**Зачем:** Основной мозг бота
**Где взять:**
1. Перейдите на https://makersuite.google.com/app/apikey
2. Создайте API ключ
3. В n8n: Settings → Credentials → Найдите "Google Gemini(PaLM) Api account"
4. Вставьте ключ

#### 3️⃣ Supabase ⚠️
**Зачем:** База знаний бота
**Где взять:**
1. Зарегистрируйтесь на https://supabase.com/
2. Создайте новый проект
3. Скопируйте Project URL и API Key (Service Role)
4. В n8n: Settings → Credentials → Найдите "Supabase account"
5. Вставьте данные

**Создайте таблицу в Supabase:**
```sql
-- Выполните в Supabase SQL Editor
create table documents (
  id bigserial primary key,
  content text,
  metadata jsonb,
  embedding vector(1536)
);

-- Создайте индекс для быстрого поиска
create index on documents using ivfflat (embedding vector_cosine_ops);
```

### Шаг 3: Загрузите базу знаний (3 минуты)

1. В n8n workflow найдите узел **"When clicking 'Execute workflow'"** (вверху)
2. Кликните **"Execute Node"**
3. Дождитесь завершения

Это загрузит информацию о личности Джарвиса в базу знаний.

### Шаг 4: Протестируйте бота (1 минута)

1. Откройте Telegram
2. Найдите @Baga_assistant_bot
3. Отправьте: "Привет, как тебя зовут?"

**Ожидаемый результат:** Бот должен представиться как "Джарвис"

## ⚠️ Если бот не работает

### Проблема: Бот не отвечает вообще
**Решение:**
1. Проверьте, активен ли workflow в n8n
2. Проверьте Telegram Bot Token в credentials
3. Посмотрите Executions в n8n - есть ли ошибки?

### Проблема: Бот отвечает, но странно
**Решение:**
1. Убедитесь, что Google Gemini API настроен
2. Проверьте, что база знаний загружена (Шаг 3)
3. Посмотрите логи в n8n Executions

Для полной функциональности бота нужно настроить дополнительные сервисы:

- OpenRouter/OpenAI API (GPT-4o-mini)

**Для памяти разговоров:**
- PostgreSQL база данных

**Для веб-поиска:**
- Google Custom Search API (уже настроен)

**Для обработки Word документов:**
- ConvertAPI (уже настроен)
