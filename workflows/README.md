# n8n Workflows для Jarvis Assistant

## Обзор

Этот проект использует **n8n** для создания интеллектуального Telegram-бота с AI-возможностями.

**Имя бота:** Baga_assistant_bot (@Baga_assistant_bot)
**n8n instance:** https://n8n.kir-ito.ru/

---

## Структура Workflow

### Основной workflow: `paraplexity-3.0.json`

Это продвинутая схема AI-ассистента "Джарвис" с следующими возможностями:

#### 🎯 Основные функции:

1. **Обработка текстовых сообщений**
   - Прямая обработка текстовых запросов через AI

2. **Голосовые сообщения**
   - Распознавание речи через OpenAI Whisper API
   - Автоматическая транскрипция аудио в текст

3. **Анализ изображений**
   - Обработка фотографий через GPT-4o-mini
   - Распознавание содержимого изображений
   - Поддержка форматов: .jpg, .jpeg, .png, .webp, .gif

4. **Обработка документов**
   - **PDF** - извлечение текста
   - **Word (.doc, .docx)** - конвертация через ConvertAPI
   - **Excel (.xls, .xlsx)** - извлечение данных
   - **JSON** - парсинг структурированных данных
   - **XML** - обработка XML-файлов

5. **RAG (Retrieval-Augmented Generation)**
   - Векторная база знаний в Supabase
   - Загрузка документов из Google Drive
   - Semantic search по загруженной информации
   - Reranking через Cohere для улучшения релевантности

6. **Память разговоров**
   - PostgreSQL Chat Memory
   - Сохранение контекста на 3 последних сообщения
   - Уникальная память для каждого пользователя (по chat_id)

7. **Веб-поиск**
   - Интеграция с Google Custom Search API
   - Получение актуальной информации из интернета

8. **Работа с датой/временем**
   - Автоматическое получение текущей даты
   - Часовой пояс: Asia/Almaty

## 📋 Процесс работы бота

### Основной поток:

1. **Telegram Trigger** → Получение сообщения
2. **"Typing…"** → Показ статуса "печатает..."
3. **Input Message Router** → Определение типа входящего сообщения:
   - Text → Extract Text
   - Audio → Download Audio → Translate to Text
   - Photo → Download Photo → Photo to text
   - Document → Проверка типа файла → Маршрутизация по типу документа

4. **Document Processing** (если документ):
   - Проверка поддерживаемых форматов
   - Скачивание файла
   - Извлечение текста/данных
   - Объединение с caption

5. **AI Agent Processing**:
   - Поиск в векторной базе Supabase (внутренние знания)
   - Веб-поиск через Google (если нужна актуальная информация)
   - Получение даты/времени
   - Загрузка памяти разговора из PostgreSQL
   - Генерация ответа через Google Gemini

6. **Response** → Отправка ответа в Telegram

### Отдельный поток для обучения:

1. **Manual Trigger** → Запуск вручную
2. **Download file** → Загрузка документов из Google Drive
3. **Vectorization** → Создание embeddings через OpenAI
4. **Add to Supabase** → Сохранение в векторную БД

## 🚀 Как запустить

### Шаг 1: Импорт workflow в n8n

1. Откройте ваш n8n инстанс: https://n8n.kir-ito.ru/
2. Создайте новый workflow
3. Импортируйте файл `paraplexity-3.0.json`

### Шаг 2: Настройка Credentials

Проверьте и настройте все credentials (см. список выше)

### Шаг 3: Обучение бота (ВАЖНО!)

**Прежде чем использовать бота, нужно загрузить базу знаний:**

1. Убедитесь, что документ "Профиль Ассистента" доступен в Google Drive
2. Найдите узел **"When clicking 'Execute workflow'"**
3. Нажмите **"Execute Workflow"** вручную
4. Дождитесь завершения загрузки в Supabase

Этот шаг нужно выполнять каждый раз при обновлении базы знаний!

### Шаг 4: Активация workflow

1. Активируйте workflow в n8n
2. Telegram webhook автоматически зарегистрируется
3. Начните общение с ботом: @Baga_assistant_bot
