## 🧠 Шаг 3: Загрузка базы знаний

**ВАЖНО:** Это критически важный шаг! Без базы знаний бот не будет знать свою личность и инструкции.

### 3.1 Проверка документа "Профиль Ассистента"
- [ ] Откройте Google Drive
- [ ] Найдите документ "Профиль Ассистента" или создайте новый
- [ ] В документе должно быть описание:
  - Кто такой Джарвис
  - Его возможности
  - Как он должен отвечать
  - Правила и приоритеты

### 3.2 Загрузка в Supabase
1. [ ] Откройте n8n workflow
2. [ ] Найдите узел **"When clicking 'Execute workflow'"** (вверху схемы)
3. [ ] Нажмите на него
4. [ ] Нажмите **"Execute Node"** или запустите весь workflow вручную
5. [ ] Дождитесь завершения (может занять 30-60 секунд)
6. [ ] Проверьте в Supabase, что таблица `documents` заполнилась данными

## 🔍 Шаг 5: Диагностика проблем

### Если бот не отвечает:
1. [ ] Проверьте в n8n, что workflow активен
2. [ ] Проверьте Telegram Bot Token
3. [ ] Посмотрите **Executions** в n8n (есть ли ошибки?)

### Если бот отвечает, но странно:
1. [ ] Проверьте, загружена ли база знаний в Supabase
2. [ ] Проверьте Google Gemini API credentials
3. [ ] Посмотрите логи выполнения в n8n

### Если не работает распознавание голоса/изображений:
1. [ ] Проверьте OpenAI/OpenRouter credentials
2. [ ] Проверьте, не закончились ли бесплатные кредиты

### Если не работает обработка документов:
1. [ ] Проверьте ConvertAPI ключ
2. [ ] Убедитесь, что формат файла поддерживается

## 📊 Шаг 6: Мониторинг и логи

### В n8n:
- [ ] Откройте **Executions** (история выполнений)
- [ ] Проверьте последние выполнения workflow
- [ ] Если есть ошибки (красные), кликните и изучите детали

### Типичные ошибки и решения:

**Error: Unauthorized (401)**
- Проблема: Невалидный API ключ
- Решение: Обновите credentials для соответствующего сервиса

**Error: Rate limit exceeded**
- Проблема: Превышен лимит запросов
- Решение: Подождите или обновите план подписки

**Error: Table does not exist**
- Проблема: Не создана таблица в Supabase/PostgreSQL
- Решение: Создайте таблицу вручную
